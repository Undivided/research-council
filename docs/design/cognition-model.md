# Research Council Cognition Model

## Purpose

This document records the emerging theoretical model of cognition developed from Research Council v0.1 experiments.

It is not a benchmark specification. It is an interpretation layer derived from experimental observations.

## Core Observation

Research Council experiments suggest that cognitive behavior is not determined solely by the underlying model.

A system's behavior emerges from the interaction between:

- model capability
- institutional roles
- memory
- retrieval mechanisms
- environmental constraints
- feedback loops

## Working Model

A cognitive system can be represented as:

    Cognition =
    Model
    + Roles
    + Memory
    + Retrieval
    + Environment
    + Feedback

## Model

The underlying language model provides general reasoning capability, pattern recognition, and generation.

## Roles

Specialized roles create different perspectives and cognitive pressures.

Examples:

- Researcher
- Historian
- Philosopher
- Strategist
- Skeptic
- Red Team
- Editor

## Memory

Knowledge availability changes reasoning behavior.

Research Council experiments demonstrated that changing institutional memory changed the behavior of the same configured model.

## Retrieval

The method by which information reaches agents is part of the cognitive process.

Memory that exists but cannot be retrieved is functionally different from available memory.

## Environment

Filesystem structure, configuration, and runtime assumptions influence the behavior of the institution.

Reproducibility findings demonstrated that environmental coupling can alter cognitive conditions.

## Feedback

Critique, revision, and evaluation loops allow systems to refine outputs.

## Research Direction

Future experiments should investigate how adding richer environments changes institutional cognition:

- structured data
- simulations
- graphs
- geometric reasoning
- external tools
