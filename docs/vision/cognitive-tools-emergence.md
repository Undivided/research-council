# Cognitive Tools as Emergent Artifacts

## Seed Principle

The Council should not merely store answers. It should discover, test, and preserve patterns of reasoning that improve future decisions.

Mental models are not commandments. They are compressed discoveries: patterns humans have found useful after repeated contact with reality.

## The Emergence Rule

Do not begin by forcing a catalog of mental tools into the system.

Create an environment where useful tools can emerge:

- observe recurring structures
- test whether they generalize
- record when they fail
- preserve conditions where they are useful

The goal is not to memorize names like Pareto principle, risk/reward modeling, or decision frameworks. The goal is to understand the underlying patterns that made those tools valuable.

## Example: Pareto-Like Reasoning

A brittle system says:

"Always apply the 80/20 rule."

A Turtle system asks:

- Are contributions unevenly distributed?
- Are there leverage points?
- Are a small number of causes producing a large portion of outcomes?

The named rule is a compressed observation. The deeper pattern is what matters.

## Example: Decision Frameworks

Risk/reward analysis, reversibility, time horizons, opportunity cost, and expected value can emerge naturally from agents examining:

- uncertainty
- possible outcomes
- consequences
- available resources
- ability to recover from failure

## Cognitive Tool Lifecycle

1. Discover a pattern.
2. Test where it applies.
3. Identify failure modes.
4. Preserve the useful abstraction.
5. Make it available for future reasoning.

## Ferriss-Style Compression Insight

One valuable human skill is collecting and compressing useful strategies from many domains.

A future Council should be able to perform a similar function:

- gather patterns
- compare experiences
- extract principles
- maintain context
- avoid turning tools into dogma

## North Star

A good cognitive tool does not replace thinking. It improves the process that creates thinking.

The Council should become a compression engine for useful patterns while preserving uncertainty, disagreement, and the ability to revise itself.
