# Outside Influences Map

**Status:** Living research map

**Captured:** 2026-09-11

This document is the shared map for outside frameworks, research programs, and conceptual tools that may illuminate Research Council, the Agora, Full Turtle / The Long Recursion, and future model training.

The purpose is not to collect impressive names or force the project into someone else's theory.

The method is:

**borrow mechanisms, not mythology.**

For each influence:

1. identify the smallest useful mechanism or structural idea;
2. identify what problem it solved in its original domain;
3. distinguish established work from interpretation, marketing, or speculation;
4. map only the correspondence that actually holds;
5. design a small experiment when the idea becomes actionable;
6. observe before explaining;
7. preserve failures, surprises, and mismatches;
8. leave the grand theory for later.

A recurring project signal is:

> **If the parts make each other make more sense, investigate the system.**

That is a reason to look more closely, not proof that two fields are secretly identical.

    Reality
        ↓
    Observation
        ↓
    Model
        ↓
    Tool / Intervention
        ↓
    New Observation
        ↓
    Improved Model

A compact Full Turtle loop is:

    Explore
        ↓
    Understand
        ↓
    Build
        ↓
    Teach
        ↓
    Delegate
        ↓
    Observe
        ↓
    Learn
        ↓

The working hypothesis is not that these loops are the same thing.

It is that several useful domains may share deeper structural motifs involving feedback, representation, constraint, emergence, and recursive adaptation.

# 2. Status Key

## Integrated

Already materially reflected in project design or experiments.

## Reviewed

Outside work has been examined enough to identify concrete useful correspondences and limits.

## Queued

Promising influence to investigate later. No strong project claim should be made yet.

## Speculative

Interesting idea with weak, preliminary, proprietary, or otherwise insufficient evidence. Preserve separately from established work.

# 4. Established Lessons Already Worth Carrying Forward

## A. Structure can reduce learning burden

Geometric Deep Learning supplies a concrete example: if relevant symmetry or relational structure is known, architecture can encode it rather than requiring the learner to rediscover it from raw examples.

Project translation:

> **Explicit structure changes what the learner needs to learn.**

This is potentially important for:

- provenance;
- claim/evidence relationships;
- world models;
- spatial reasoning;
- causal structure;
- future robot embodiment;
- future specialized model training.

## B. Proposal and verification need not be one operation

AlphaGeometry gives a clean instance of neural proposal plus symbolic verification.

Research Council already points in the same direction:

    generate
        ↓
    challenge
        ↓
    verify / constrain
        ↓
    adjudicate
        ↓
    preserve

Future systems should use the substrate best suited to each function instead of asking one model to perform every operation opaquely.

## C. Relationships can deserve first-class representation

Flat text is useful but may be insufficient for some questions.

Possible future explicit relations include:

    claim ──supported-by── evidence
      │
      ├──contradicts── claim
      ├──depends-on── assumption
      ├──derived-from── source
      └──adjudicated-by── disposition

This could make structural questions answerable without pretending that epistemology is literally Euclidean geometry.

## D. Some consequences must unfold

The useful methodological lesson from computational irreducibility is not that every project process is formally irreducible.

It is a discipline:

> **Do not assume every important consequence can be inferred from the parts without running the interaction.**

That supports the project's existing habit of building small experiments and preserving what actually happens.

## E. The observer is inside the loop

Research Council changes its durable knowledge environment.

That knowledge environment changes later reasoning.

Full Turtle lets the player alter worlds and learners which later alter the player.

The observer / learner is therefore not always external to the system being studied.

This should remain an explicit research concern.

# 5. Emerging Project-Level Questions

The influence map is intended to generate experiments, not just analogies.

Questions now worth preserving include:

1. What are the smallest useful epistemic primitives?
2. Which interaction rules between them matter most?
3. Which structures are true primitives, and which are emergent conveniences?
4. Which relations should become explicit machine-readable objects?
5. What is lost when an epistemic relation is serialized only as prose?
6. Can a claim/evidence/provenance graph improve retrieval or adjudication?
7. Can we measure information flow between cognitive roles?
8. What topology best preserves productive disagreement without producing noise?
9. Which failures arise from model weakness, and which arise from poor institutional structure?
10. Can the same base model produce meaningfully different higher-order behavior under different epistemic rules?
11. Can synthetic environments teach generalizable relational reasoning?
12. Which capabilities should be learned, and which should be guaranteed by explicit constraints or external tools?
13. What invariants persist across different Council architectures, models, games, or embodiments?
14. Which apparent analogies break under experiment?
15. What must persist for a lifelong companion to remain meaningfully continuous across model, body, or memory changes?

# 6. Future Epistemic Rule-Space Explorer

A long-term Research Council direction is to stop treating one Council architecture as the only candidate and instead explore families of institutions.

Possible axes:

    cognitive roles
        ×
    information topology
        ×
    memory policy
        ×
    retrieval policy
        ×
    challenge structure
        ×
    adjudication rules
        ×
    representation substrate
        ×
    environment / tool access

Possible observed outcomes:

- error correction;
- calibration;
- disagreement preservation;
- convergence quality;
- novelty;
- robustness;
- recovery from bad assumptions;
- provenance integrity;
- memory quality;
- ability to change models when reality pushes back;
- ability to transfer learning to a changed environment.

This should eventually become experimental infrastructure rather than a philosophical diagram.

The question is:

> **Which small combinations of epistemic rules reliably produce useful higher-order cognitive behavior?**

# 7. Full Turtle Correspondence

Full Turtle is not a visualization of Research Council.

It may nevertheless become an experiential laboratory for some of the same fundamentals:

- build an environment;
- teach an agent through that environment;
- let the agent act beyond direct control;
- observe what emerges;
- discover where the player's model was incomplete;
- revise the player, agent, environment, or all three;
- repeat at another scale.

This makes the world itself part of cognition.

The strongest recurring principle remains:

> **Rules make worlds. Worlds make minds. Minds rewrite worlds.**

And the systems-thinking signal remains:

> **The whole thing reflects into the whole thing.**

A mechanic, relationship, institution, or world is especially interesting when it contains a small version of the larger recursive structure.

# 8. Research Discipline

Do not make outside influence collecting into a new form of premature theory-building.

For each queued framework:

- read primary or high-quality sources;
- extract concrete mechanisms;
- write down what does **not** transfer;
- identify one falsifiable or inspectable experiment;
- run it when project maturity makes the experiment cheap enough;
- record the result even when nothing interesting happens.

The project currently prefers:

**fundamentals → structure → interaction → observation → notes → revision**

over:

**grand explanation → forced mapping → confirmation.**

Why can wait.

What happens comes first.
