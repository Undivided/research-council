# R0.5-007 Safe Run Resumption

## Question

Can the Research Council resume a durably interrupted run without re-executing
agents that already completed and without duplicating durable institutional
actions?

## Motivation

R0.5-006 established first-class interrupted run state.

A catchable interruption can now leave:

    run_status: interrupted
    reason: process_interrupted
    current_agent: <agent>
    attempted_agents: N
    completed_agents: M

This makes interruption explicit, but recovery is still manual.

Restarting the Council from the beginning would replay already-completed work.

That risks:

- unnecessary model execution
- changed downstream context
- duplicate artifacts
- duplicate durable memory
- duplicate institutional actions

Therefore:

    restart
    !=
    resume

## Initial Resumption Rule

R0.5-007 will resume from the interrupted agent.

Agents that already completed successfully must not execute again.

The interrupted in-flight agent is restarted from its beginning.

Example:

    researcher: completed
    historian: interrupted

Resume behavior:

    researcher -> skipped
    historian -> executed again
    remaining agents -> executed normally

R0.5-007 does not attempt continuation inside a partially executed model call.

## Source of Truth

Resumption must use durable runtime state rather than natural-language inference.

Relevant sources include:

    run-state record
    R0.5-004 per-agent outcome records
    existing promoted artifacts

A completed agent is identified by a durable successful agent outcome associated
with the same run.

Missing outcomes are not interpreted as successful completion.

## Run Identity

Initial R0.5-007 behavior should preserve the original run identity.

A resumed execution remains continuation of the interrupted run rather than a
new independent Council run.

Therefore:

    original run_id == resumed run_id

## State Transition

Before resume:

    run_status: interrupted

When resumption begins:

    run_status: running
    reason: resumed_execution

When execution completes normally:

    run_status: completed
    reason: success

If execution is interrupted again:

    run_status: interrupted
    reason: process_interrupted

## Completed-Agent Safety

Already completed agents must:

- not invoke the model again
- not produce new raw output
- not produce replacement analysis artifacts
- not receive duplicate outcome records

Their existing evidence remains authoritative.

## Interrupted Agent

The interrupted agent may have:

- no outcome record
- a zero-byte raw path
- a partial raw path
- no promoted artifact

The first implementation will restart that agent from the beginning.

Any stale incomplete raw file for that agent must not be mistaken for a valid
promoted artifact.

## Durable Institutional Actions

Resumption must not replay already completed institutional actions.

In particular, future controls must verify that already completed Judge or
Archivist operations are not duplicated merely because execution resumed later.

## Success Criteria

PASS requires:

- an interrupted run can be selected explicitly for resumption
- original run_id is preserved
- already completed agents are skipped
- skipped agents are not invoked again
- skipped agents receive no duplicate outcome record
- interrupted agent restarts from its beginning
- remaining agents execute normally
- attempted/completed counts remain coherent
- final run state becomes completed/success
- final human-readable run record is created once
- R0.5-002 disposition behavior remains correct
- R0.5-003 artifact boundaries remain correct
- R0.5-004 agent outcomes remain correct
- R0.5-005 whole-run state remains correct
- R0.5-006 interruption handling remains correct

## Non-Goals

R0.5-007 does not provide:

- continuation inside a model generation
- distributed recovery
- automatic startup discovery
- retry policy
- multiple competing resumptions
- rollback of external side effects
- SIGKILL detection
- power-loss detection
- general event sourcing

## Architectural Principle

Recovery should continue known work, not silently replay completed institutional
history.
