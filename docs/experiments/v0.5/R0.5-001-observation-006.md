# R0.5-001 Observation 006

## Finding

The runtime integrity defect identified in Observation 005 was repaired and
functionally tested.

The Council runner now checks whether the model invocation succeeds before
admitting its output as a cognitive artifact.

If the model invocation fails, the runtime removes the partially created
output file and halts the run before provenance creation or downstream
processing.

## Implementation

Commit:

    e13e97e Fail fast on invalid model artifacts

The runtime now applies two checks immediately after model invocation:

1. The `ollama run` command must return successfully.
2. The resulting artifact must be nonempty.

If either condition fails, the candidate artifact is removed and the Council
run terminates.

Provenance creation occurs only after these checks.

## Functional Test

A temporary copy of the Council runner was configured with a deliberately
nonexistent model:

    definitely-not-a-real-model:invalid

The disposable project was:

    _failfast-test

The Researcher invocation failed with:

    Error: pull model manifest: file does not exist
    ERROR: Model invocation failed for researcher

The Council halted immediately.

A filesystem inspection of the disposable project after failure found no
files.

Therefore the failed invocation did not leave behind:

- a zero-byte cognitive artifact
- provenance for the failed artifact
- downstream Council outputs

The disposable project and temporary runner were then removed.

The repository working tree was clean after cleanup.

## Verification Status

The invocation-failure branch is FUNCTIONALLY VERIFIED:

    model invocation failure
    -> runtime detects failure
    -> partial artifact removed
    -> run aborts
    -> no provenance created
    -> no downstream processing

The separate branch in which a model invocation exits successfully but
produces an empty artifact has been implemented and syntax-checked but has
not yet been independently forced in a functional test.

Therefore this observation verifies the failure-handling behavior demonstrated
by the quota incident without claiming broader validation than the test
supports.

## Experimental Status

This runtime repair does not complete R0.5-001.

The remaining first-class provenance success criterion is still:

    institutional memory distinguishes exploratory from accepted material

That criterion remains UNTESTED by the quota-failed run.

## Architectural Principle

Provenance may describe an admitted cognitive artifact.

It must not manufacture the appearance of cognition merely because an
invocation was attempted.
