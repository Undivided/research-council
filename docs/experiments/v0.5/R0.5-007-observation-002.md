# R0.5-007 Observation 002

## Deterministic Safe-Resumption Validation

PASS.

R0.5-007 was tested with deterministic model shims across two interruption
positions.

The tests examined both execution replay and institutional side-effect replay.

## Control A — Early Interruption

The Council was interrupted while the Historian was executing.

Before interruption:

    researcher: completed
    historian: attempted but incomplete

The durable run state recorded:

    run_status: interrupted
    current_agent: historian
    attempted_agents: 2
    completed_agents: 1

On resume, the original run identity was reused.

The completed Researcher was restored from its successful R0.5-004 outcome and
promoted artifact rather than invoked again.

The interrupted Historian was restarted from its beginning.

Invocation counts after completion were:

    researcher: 1
    historian: 2
    philosopher: 1
    strategist: 1
    skeptic: 1
    red-team: 1
    fool: 1
    editor: 1
    judge: 1
    archivist: 1
    librarian: 1

The final run contained:

    run_status: completed
    reason: success
    attempted_agents: 11
    completed_agents: 11
    total_agents: 11

There were eleven successful agent outcomes under one run ID.

There were twelve raw attempts because the interrupted Historian attempt was
preserved.

There were eleven promoted analysis artifacts.

This establishes:

    resume
    !=
    restart from scratch

and:

    interrupted attempt evidence
    !=
    successful promoted artifact

## Control B — Post-Institutional Interruption

A second run was interrupted during Librarian execution.

By that point, Judge and Archivist had already completed.

The interrupted state represented:

    current_agent: librarian
    attempted_agents: 11
    completed_agents: 10

The Judge had already created one durable disposition record.

The Archivist had already created one durable knowledge entry.

On resume:

    Judge was not invoked again.
    Archivist was not invoked again.
    Librarian restarted from its beginning.

Final invocation counts were:

    researcher: 1
    historian: 1
    philosopher: 1
    strategist: 1
    skeptic: 1
    red-team: 1
    fool: 1
    editor: 1
    judge: 1
    archivist: 1
    librarian: 2

Exactly eleven successful R0.5-004 outcomes existed.

No failed outcome was manufactured for the interrupted Librarian attempt.

The final run state was:

    run_status: completed
    reason: success
    current_agent: null
    failed_agent: null
    attempted_agents: 11
    completed_agents: 11
    total_agents: 11

## Stable Run Identity

Resumption preserved the original run ID.

The state file, agent outcomes, and final human-readable run record therefore
remained members of one logical Council execution.

A resumed execution did not create a second run identity.

## Attempted-Agent Semantics

R0.5-007 refined the meaning of:

    attempted_agents

It now represents the furthest Council position entered in the logical run,
rather than the number of process-level invocation attempts.

Therefore retrying an interrupted Historian did not produce:

    attempted_agents: 12

The completed eleven-agent run correctly ended at:

    attempted_agents: 11

## Durable Run Inputs

New runs now persist system-owned resumption inputs including:

    research question
    model identity
    Council agent roster and order
    run-start knowledge context
    run-start retrieval context

Resumption loads these durable inputs rather than reconstructing them from the
current environment.

The runtime refuses resumption when required snapshots are absent or when
durable run identity or Council structure is inconsistent.

## Context-Stability Control

The Council normally has two knowledge-derived context paths:

1. full knowledge-entry context
2. question-based retrieval context

Both are mutable if rebuilt from the live knowledge tree.

R0.5-007 therefore snapshots both at initial run creation.

During the post-institutional interruption control, a sentinel knowledge file
was deliberately added after the original process had terminated:

    R05007_POST_INTERRUPT_SENTINEL_DO_NOT_SEE

The sentinel existed in live canonical knowledge before resumption.

It did not exist in either durable run-start context snapshot.

Both the interrupted Librarian attempt and the resumed Librarian attempt
reported:

    context_clean

The sentinel was never observed in the model prompt.

This provides a causal control showing that resumed execution reused the
original epistemic starting point rather than silently rebuilding context from
mutated canonical memory.

## Institutional Side-Effect Integrity

The post-institutional control produced exactly:

    one Judge disposition record
    one Archivist knowledge entry

Judge and Archivist were not replayed during resumption.

No duplicate institutional side effects were created.

The disposition record, Archivist entry, and sentinel control file were copied
into project evidence and removed from canonical knowledge after validation.

## Process-Local Reconstruction

Successful prior artifacts were reconstructed into process-local Council state
on resume.

This allows skipped artifacts to remain available for:

    accumulated outputs
    Fool identity
    Editor output
    Judge output
    downstream handoff state
    final human-readable run record

without model reinvocation.

## Compatibility

R0.5-002 durable disposition remained functional.

R0.5-003 raw/promoted artifact separation remained functional.

R0.5-004 per-agent outcomes remained functional.

R0.5-005 whole-run state remained coherent.

R0.5-006 interruption handling remained functional.

No provenance-sidecar runtime was restored.

## Limitations

R0.5-007 does not provide:

- continuation inside an interrupted model generation
- automatic discovery of resumable runs
- resumption of prior failed agent outcomes
- competing-resumer coordination
- distributed leases
- rollback of arbitrary external side effects
- SIGKILL detection
- power-loss detection
- generalized event sourcing

The initial implementation intentionally resumes only runs whose durable state
is explicitly:

    interrupted

and whose already-existing outcomes form a safe successful prefix.

## Conclusion

R0.5-007 passes deterministic safe-resumption validation.

An interrupted Council run can continue under the same run identity without
replaying completed agents, without duplicating completed Judge or Archivist
actions, and without changing its original knowledge context merely because the
process restarted.
