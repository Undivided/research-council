# R0.5-003 Observation 001

## Observation

The R0.5-002 real-model validation exposed visible generation preamble across
the Council's agent artifacts.

The issue was not isolated to the Fool.

Observed roles included:

    researcher
    historian
    philosopher
    strategist
    skeptic
    red-team
    fool
    editor
    judge
    archivist
    librarian

Artifacts commonly began with:

    Thinking...

followed by generated reconstruction or summarization of some combination of:

    agent identity
    research question
    cognitive-function instructions
    output constraints
    previous knowledge
    current Council reports

The generated material preceded the intended substantive report.

## Finding

The current runtime treats the complete model emission as the cognitive
artifact.

Therefore the system presently has no explicit distinction between:

    raw generation stream

and:

    validated cognitive artifact

## Scope

This is a Council-wide artifact-boundary problem.

It should not be repaired as a Fool-specific normalization rule.

## Implication

Any future use of Council artifacts as:

    downstream context
    durable-memory material
    artifact snapshots
    evaluation corpora
    synthetic training data

may preserve generation preamble and prompt reconstruction unless an explicit
artifact boundary is introduced.

## Constraint

The observed raw generations are experimental evidence.

They should not be rewritten or normalized retroactively.

R0.5-003 should preserve raw emission while separately validating the canonical
artifact that is eligible for downstream institutional use.
