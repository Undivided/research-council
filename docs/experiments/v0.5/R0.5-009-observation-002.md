# R0.5-009 Observation 002

## Deterministic Terminal-Publication Controls

PASS.

R0.5-009 was tested at both sides of canonical run-record publication.

## Control A — Interruption Before Run-Record Publication

Project:

    r0.5-009-before-run-record

The process was interrupted after all eleven agents had completed but before
the canonical run record was published.

Durable state became:

    run_status: interrupted
    reason: process_interrupted
    attempted_agents: 11
    completed_agents: 11

Exactly eleven successful agent outcomes existed.

Exactly eleven model invocations had occurred.

The canonical run record did not yet exist.

The interrupted run was then resumed.

Resume skipped all eleven already-completed agents.

Model invocation count remained:

    11 -> 11

The resumed process created the final run record and published:

    run_status: completed
    reason: success
    attempted_agents: 11
    completed_agents: 11

No Council agent was replayed.

## Control B — Interruption After Run-Record Publication

Project:

    r0.5-009-after-run-record

The process atomically published the complete canonical run record and was
then interrupted before terminal whole-run state publication.

Durable state became:

    run_status: interrupted
    reason: process_interrupted
    attempted_agents: 11
    completed_agents: 11

Exactly eleven successful outcomes existed.

The complete canonical run record already existed.

This state is valid by design.

The interrupted run was resumed despite the pre-existing canonical run
record.

Resume skipped all eleven completed agents.

Model invocation count remained:

    11 -> 11

The final whole-run state became:

    run_status: completed
    reason: success
    attempted_agents: 11
    completed_agents: 11

The canonical run record remained present.

## Institutional Side Effects

Before and after Control B resume, the canonical institutional side effects
were identical.

The memory-file set contained one Fool disposition record and one Archivist
entry.

The before/after memory diff was empty.

Therefore recovery did not replay Judge or Archivist institutional actions.

Synthetic memory from both deterministic controls was preserved under each
project's evidence directory and removed from canonical knowledge.

## Resulting Semantics

R0.5-009 establishes:

    run-record existence
    !=
    terminal-state publication

and:

    run_status: completed
    =>
    complete canonical run record already exists

The whole-run state is now the authoritative publication point.

## Conclusion

Both deterministic terminalization interruption windows pass.

The system can recover safely from interruption both before and after
canonical run-record publication without replaying completed Council agents
or duplicating institutional side effects.
