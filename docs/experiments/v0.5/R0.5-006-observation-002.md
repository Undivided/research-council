# R0.5-006 Observation 002

## Deterministic Runtime Validation

PASS.

R0.5-006 was tested using deterministic Ollama shims and three catchable Unix
signals:

    SIGINT
    SIGTERM
    SIGHUP

In each control, the Researcher completed normally.

The Historian was then attempted and the Council process received the test
signal while the Historian model invocation was in progress.

## Partial Raw Files

In interruption controls, shell redirection may create a zero-byte raw-file
path for the in-flight agent before the model process produces output.

This does not imply that a model artifact existed.

The run-state record remains authoritative about the interruption.

R0.5-006 therefore does not infer completed or failed agent state from the mere
presence of a filesystem path.

## Agent-State Integrity

The interrupted Historian did not receive:

    invocation_status: failed
    agent_status: failed

because the invocation did not return through a normal R0.5-004 failure path.

This preserves an important distinction:

    normally failed agent operation
    !=
    process interruption during agent execution

## Run-State Integrity

All three signal controls produced the same durable institutional meaning:

    run_status: interrupted
    reason: process_interrupted

The signal-specific shell exit code remains an operating-system concern.

The durable Council state expresses the institutional execution condition.

## Compatibility

R0.5-004 outcomes already written for completed agents remained intact.

R0.5-005 run-state counters remained correct.

No final successful run record was falsely produced.

R0.5-003 artifact semantics were unchanged.

No provenance-sidecar mechanism was restored.

## Limitation

This experiment covers catchable process signals only.

It does not establish durability for:

    SIGKILL
    sudden power loss
    kernel failure
    filesystem failure
    catastrophic process termination before the handler executes

Those conditions may leave a durable state of:

    running / in_progress

and remain a separate future problem.

## Conclusion

R0.5-006 passes deterministic validation for SIGINT, SIGTERM, and SIGHUP.

A catchable interruption no longer forces the durable Council state to pretend
that execution is still active.

The runtime can explicitly preserve an interrupted run without falsifying the
state of the in-flight agent.
