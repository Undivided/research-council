# R0.5-007 Observation 001

## Source Observation

R0.5-006 proved that a Council process can terminate during an agent and leave
explicit durable state:

    run_status: interrupted
    current_agent: historian
    attempted_agents: 2
    completed_agents: 1

The completed Researcher retained its successful R0.5-004 outcome.

The interrupted Historian had no fabricated normal failure outcome.

## Remaining Problem

The system can now identify interrupted execution but cannot continue it.

Running the Council normally again would create a new execution from the first
agent and would replay work already known to have completed.

## Required Distinction

The next layer must distinguish:

    new run

from:

    continuation of an existing interrupted run

and:

    completed agent

from:

    agent that must execute during resumption

## Initial Safety Choice

An agent interrupted in flight should be restarted from its beginning.

Already completed agents should not be executed again.

This provides a conservative recovery boundary without claiming checkpointing
inside model inference.

## Implication

Safe resumption should be established before automatic retry or broader crash
recovery is introduced.
