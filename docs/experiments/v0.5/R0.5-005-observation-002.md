# R0.5-005 Observation 002

## Deterministic Runtime Validation

PASS.

R0.5-005 was tested using deterministic Ollama shims.

The tests exercised whole-run state independently from per-agent state.

## Control A — Terminating Failure

The Researcher completed successfully.

The Historian model invocation succeeded but its artifact failed R0.5-003
boundary validation because the closing delimiter was missing.

The durable run-state record contained:

    run_status: failed
    reason: agent_failure
    current_agent: historian
    failed_agent: historian
    attempted_agents: 2
    completed_agents: 1
    total_agents: 11

The Researcher had a successful R0.5-004 outcome.

The Historian had:

    invocation_status: succeeded
    artifact_status: rejected_at_boundary
    agent_status: failed
    reason: invalid_boundary_count

No final human-readable run record was created.

The system therefore represented the failed run directly rather than requiring
later inference from missing agent outputs or absent run records.

## Control B — Completed Run with Nonfatal Agent Failure

All eleven agents were attempted.

The Archivist model invocation succeeded and its artifact was promoted, but its
agent-specific durable-memory validation failed because the artifact omitted:

    ARCHIVAL REPORT

The Archivist outcome contained:

    invocation_status: succeeded
    artifact_status: promoted
    agent_status: failed
    reason: archivist_report_missing

The runtime continued to Librarian.

The Librarian completed successfully.

The final run-state record contained:

    run_status: completed
    reason: completed_with_agent_failure
    current_agent: null
    failed_agent: null
    attempted_agents: 11
    completed_agents: 10
    total_agents: 11

A final human-readable run record was created.

This demonstrates:

    agent failure
    !=
    run failure

and:

    run completed
    !=
    every agent succeeded

## Control C — Fully Successful Run

All eleven agents completed successfully.

The final run-state record contained:

    run_status: completed
    reason: success
    current_agent: null
    failed_agent: null
    attempted_agents: 11
    completed_agents: 11
    total_agents: 11

Eleven R0.5-004 outcome records existed.

No agent outcome contained:

    agent_status: failed

The run-state record, all agent outcome records, and the final run record shared
one system-owned run identity.

The Judge successfully exercised R0.5-002 durable disposition.

All model outputs exercised R0.5-003 artifact-boundary validation.

## State Distinctions

The deterministic controls establish that the Council can durably distinguish:

    run currently executing

    run failed before all agents were attempted

    run reached its endpoint with a nonfatal agent failure

    run reached its endpoint with all agents successful

Whole-run state is therefore independent from any one agent's state.

## Agents Never Attempted

In the terminating-failure control:

    attempted_agents: 2
    total_agents: 11

The remaining nine agents were therefore explicitly outside the attempted
portion of the run.

Their missing outcome records no longer have to carry the entire meaning of
"not attempted."

## Compatibility

R0.5-004 per-agent outcome records remained functional.

R0.5-003 artifact-boundary behavior remained functional.

R0.5-002 durable disposition remained functional on successful Judge
operations.

No provenance-sidecar runtime was reintroduced.

## Memory Hygiene

Synthetic disposition and Archivist knowledge records generated during the
controls were copied into their corresponding project evidence directories and
removed from canonical `knowledge/entries/`.

## Qualification

R0.5-005 does not provide:

- retry behavior
- execution resumption
- process crash recovery
- distributed coordination
- scheduling
- event sourcing

It only makes whole-run state durable and explicit.

## Conclusion

R0.5-005 passes deterministic runtime validation.

A Council run no longer has to complete successfully before the system can
remember that it existed, what state it reached, how many agents were attempted,
and whether execution terminated or reached its normal endpoint.
