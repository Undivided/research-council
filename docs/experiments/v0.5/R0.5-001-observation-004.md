# R0.5-001 Observation 004

## Finding

The no-sidecar control reproduced the Editor's exploratory classification of
Fool contributions without either embedded provenance or a provenance sidecar.

This demonstrates that the previously observed exploratory classification is
not sufficient evidence of causal provenance uptake.

## Control Verification

The Fool report contained no embedded provenance metadata.

No provenance sidecar was generated.

The only Fool artifact was:

    fool-task-001-054302.md

## Editor Result

The Editor preserved language including:

- exploratory
- disruptive/exploratory
- provenance

However, the Editor did not reference:

- R0.5-001
- the Fool artifact ID
- sandbox
- a provenance sidecar

This behavior closely matched the sidecar-only condition.

## Comparison

Sidecar-only condition:

- embedded provenance: NO
- provenance sidecar: YES
- Fool classified as exploratory: YES
- sidecar-specific markers reflected downstream: NO

No-sidecar control:

- embedded provenance: NO
- provenance sidecar: NO
- Fool classified as exploratory: YES
- sidecar-specific markers reflected downstream: NO

## Interpretation

The Editor's exploratory classification can be produced by role identity and
the Editor's existing contract without access to the provenance sidecar.

Therefore, the sidecar's causal contribution to Editor cognition was not
demonstrated.

This does not invalidate first-class provenance as infrastructure.

The experiment establishes a distinction between:

- preserving provenance as institutional state
- transporting provenance between components
- causing downstream cognition to use provenance

The first two are demonstrated.

The third requires an explicit provenance-consumption mechanism or a stronger
experimental manipulation.
