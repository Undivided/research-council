# R0.5-004 Observation 001

## Source Observation

R0.5-003 deterministic malformed-boundary testing produced the following state:

    Researcher raw artifact: present
    Researcher analysis artifact: present

    Historian raw artifact: present
    Historian analysis artifact: absent

The Historian model invocation completed and emitted raw output.

Its raw generation contained an opening artifact delimiter but no closing
delimiter.

The runtime correctly rejected promotion and stopped execution.

## What the Runtime Knew

At failure time, the runtime knew:

    agent = historian
    model invocation completed
    raw output existed
    opening delimiter count = 1
    closing delimiter count = 0
    artifact promotion failed
    no canonical Historian analysis artifact was created
    execution stopped because artifact-boundary validation failed

## What Was Durably Represented

The filesystem preserved:

    raw Historian generation

and omitted:

    Historian analysis artifact

The terminal reported the validation error.

However, the operational relationship between those facts was not represented
as a dedicated machine-readable durable record.

A later observer would need to reconstruct the failure from presence, absence,
and logs.

## Finding

R0.5-003 correctly prevents malformed model output from becoming institutional
cognition.

It does not yet make the resulting operational state first-class.

Therefore:

    raw generation state
    !=
    artifact state
    !=
    run outcome state

## Implication

The same principle established by R0.5-002 applies at the execution layer:

    absence is not sufficient evidence of disposition or outcome

A missing analysis artifact may mean:

- boundary rejection
- model invocation failure
- empty generation
- interrupted process
- filesystem error
- an agent that was never attempted

Those states should not be conflated.

## Scope

R0.5-004 should introduce only the minimum durable runtime state necessary to
record agent outcomes.

It should not become a retry engine, scheduler, provenance framework, or
general workflow system.
