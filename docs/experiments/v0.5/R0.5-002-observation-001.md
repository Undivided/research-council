# R0.5-002 Observation 001

## Result

PASS — durable epistemic status and institutional disposition were preserved
as distinct machine-readable state at the durable-memory boundary, and the
causal control did not reproduce that result from natural-language role
classification alone.

## Experimental Condition

The runtime created and validated a Fool artifact, then assigned system-owned
artifact identity and epistemic status:

    artifact_id: r0.5-002-runtime-test/analysis/fool-task-001-155049.md
    epistemic_status: exploratory

The Judge supplied exactly one constrained institutional disposition:

    disposition: accepted_into_memory

The runtime then created the durable record:

    knowledge/entries/disposition-r0.5-002-runtime-test-fool-task-001-155049.md

The record preserved:

    type: disposition_record
    artifact_id: r0.5-002-runtime-test/analysis/fool-task-001-155049.md
    epistemic_status: exploratory
    disposition: accepted_into_memory

Because the disposition was accepted_into_memory, the durable record also
preserved an artifact snapshot.

A normal Archivist knowledge entry was independently created.

No provenance sidecar was created.

## Retrieval Test

The existing institutional retrieval path successfully returned the
disposition record when queried for terms including:

    fool
    exploratory
    disposition
    accepted_into_memory
    r0.5-002-runtime-test

Future institutional retrieval therefore does not need to infer either
epistemic status or institutional disposition from omission or natural-language
summary.

## Causal Control

The no-system-owned-state control used the clean runtime baseline from commit:

    8c16525 Remove experimental provenance sidecar runtime

The control deliberately preserved natural-language classification of the Fool
artifact as exploratory/sandboxed.

That classification appeared in:

- Fool output
- Editor synthesis
- Judge evaluation
- Archivist report

Despite those repeated natural-language labels:

    no disposition record was created

A normal Archivist knowledge entry was still created.

No provenance sidecar was created.

Therefore ordinary persistence succeeded while durable epistemic disposition
remained absent.

## Causal Finding

Natural-language use of "exploratory" or "sandboxed" is insufficient evidence
of durable epistemic state.

The observable difference was produced by the system-owned artifact/status
mechanism:

Experimental condition:

    system-owned artifact/status state
    +
    constrained disposition
    ->
    durable machine-readable disposition record

Control condition:

    role identity
    +
    natural-language exploratory/sandboxed prose
    ->
    no durable disposition record

This distinguishes system-owned durable state from model-generated
classification.

- exploratory status remains machine-readable at the durable-memory boundary:

  PASS

  PASS

  PASS

  PASS

## Qualification

The experimental and control runs used deterministic synthetic Ollama shims.

This intentionally isolates runtime and institutional-memory behavior from
model variance and cloud quota.

The result validates the mechanism and causal storage distinction. It does not
constitute a substantive evaluation of how reliably an unconstrained language
model would choose appropriate institutional dispositions.

## Conclusion

R0.5-002 passes at the runtime and durable-memory level.

The Council can preserve a cognitive artifact's epistemic status separately
from the institution's disposition toward that artifact without relying on
natural-language inference and without restoring the R0.5-001 provenance
sidecar runtime.
