# R0.5-003 Artifact Boundary Integrity

## Question

Can the Research Council distinguish a model's raw generation stream from the
intended cognitive artifact without relying on semantic guesses about where
reasoning, prompt reconstruction, or report content begins?

## Motivation

R0.5-002 real-model validation exposed a Council-wide artifact-boundary issue.

Agent outputs commonly begin with visible model-generated material such as:

    Thinking...

followed by reconstruction or summarization of:

- agent identity
- research question
- role instructions
- constraints
- retrieved knowledge
- current-run context

This material is currently written directly into the same file treated by the
runtime as the agent's cognitive artifact.

The behavior was observed across Council roles rather than only in the Fool.

Therefore:

    raw model emission
    !=
    validated cognitive artifact

The Council requires an explicit system-owned boundary between those objects.

## Risk

Without an artifact boundary:

    model emission
    ->
    analysis artifact
    ->
    downstream handoff
    ->
    synthesis
    ->
    durable memory
    ->
    future training data

may preserve prompt reconstruction or generation preamble as though it were
intentional cognitive output.

This can:

- contaminate downstream context
- increase prompt size
- blur reasoning and artifact boundaries
- pollute future training corpora
- make artifact snapshots include generation exhaust
- encourage successor models to imitate prompt reconstruction
- make institutional memory depend on model-specific output behavior

## Experimental Principle

Do not infer artifact boundaries from natural-language meaning.

Do not strip text merely because it begins with:

    Thinking...

Do not search for likely report headings and assume everything before them is
discardable.

The model marks the candidate artifact boundary.

The runtime validates and enforces it.

## Proposed Output Contract

Each model invocation must emit exactly one bounded artifact:

    <<<COUNCIL_ARTIFACT>>>

    <artifact content>

    <<<END_COUNCIL_ARTIFACT>>>

The runtime captures the complete model emission separately.

The runtime extracts only material occurring between the validated boundary
markers into the canonical analysis artifact.

## Storage Boundary

For the experiment:

    projects/<project>/raw/

contains the exact model emission.

    projects/<project>/analysis/

contains only the validated cognitive artifact.

Raw output is evidence.

Analysis output is institutional cognition.

The two must not be conflated.

## Required Sequence

    prompt constructed
    ->
    model invoked
    ->
    raw emission preserved
    ->
    artifact boundary validated
    ->
    bounded artifact extracted
    ->
    artifact validated
    ->
    downstream Council processing

## Validation Rules

A valid model emission must contain:

    exactly one <<<COUNCIL_ARTIFACT>>>
    exactly one <<<END_COUNCIL_ARTIFACT>>>

The opening marker must occur before the closing marker.

The extracted artifact must be non-empty.

If validation fails:

    do not guess
    do not strip heuristically
    do not send malformed output downstream

The invocation must fail explicitly or enter the existing failure path.

## Causal Control

Baseline:

    raw model emission is written directly to analysis/

Experimental condition:

    raw model emission is preserved separately
    +
    explicit artifact markers are validated
    +
    only bounded content enters analysis/

The experiment must demonstrate an observable difference in the analysis
artifact while preserving the complete raw emission for inspection.

## Success Criteria

PASS requires all of the following:

- raw model output is preserved exactly
- canonical analysis output contains only the bounded artifact
- visible `Thinking...` or prompt reconstruction outside the boundary does not
  enter downstream analysis
- downstream agents consume the clean artifact rather than raw emission
- malformed or ambiguous boundaries fail explicitly
- no semantic heuristic determines the artifact boundary
- normal Council execution remains functional
- R0.5-002 machine-readable disposition behavior remains functional
- raw evidence remains available for future audit, debugging, and model
  lineage

## Failure Modes

Failure includes:

- deleting raw evidence
- guessing artifact boundaries from prose
- silently accepting multiple boundaries
- passing raw model output downstream
- accidentally stripping legitimate report content
- breaking Judge disposition extraction
- breaking Archivist persistence
- creating model-specific cleanup rules
- expanding the experiment into a general output-processing framework

## Architectural Principle

Preserve what the model said.

Promote only what the system validated as the artifact.

## Status

Experiment defined.

No runtime implementation yet.

## Deterministic Experimental Result

The runtime mechanism passed deterministic validation.

A correctly bounded generation preserved its complete raw emission while only
the bounded report content was promoted into `analysis/`.

A malformed generation with a missing closing marker remained preserved under
`raw/` and produced no canonical analysis artifact.

A complete synthetic Council run demonstrated that:

- raw generation remained available for audit
- visible generation preamble did not enter canonical analysis
- artifact markers did not enter canonical analysis
- downstream Council processing continued using clean artifacts
- R0.5-002 Judge disposition parsing remained functional
- durable disposition records remained functional
- normal Archivist persistence remained functional
- no provenance sidecars were restored
