# R0.4-003 Cognitive Provenance Layer

## Question

Can the Research Council preserve the origin conditions of ideas as they move through synthesis and memory?

## Context

R0.4-002 demonstrated that sandbox boundaries can alter cognitive behavior.

The Fool sandbox generated alternative frames by operating without inherited institutional context.

However, downstream archival processing treated sandbox output as ordinary research output.

This created a provenance failure.

## Hypothesis

Ideas require metadata describing the conditions under which they were generated.

Content alone is insufficient.

## Proposed Provenance Model

Every significant output should be able to identify:

### Origin

- generating agent
- sandbox environment
- experiment identifier
- context mode

### Available Context

- provided information
- permitted memory
- allowed references

### Restricted Context

- withheld knowledge
- excluded conclusions
- blocked synthesis

### Classification

Possible states:

- exploratory
- evaluated
- approved
- institutional

## Evaluation

Determine whether provenance metadata improves:

- archival accuracy
- preservation of uncertainty
- separation of exploration from consensus
- future interpretation of knowledge entries

## Failure Mode Being Addressed

Without provenance:

interesting exploration
        ↓
archivist
        ↓
appears as established knowledge

With provenance:

interesting exploration
        ↓
origin preserved
        ↓
appropriate evaluation
        ↓
possible institutional memory

## Status

Design experiment for v0.4 cognitive provenance.
