# R0.4-003 Observation 003

## Finding

A clean rerun of the cognitive provenance experiment confirmed that
provenance loss occurs during Editor synthesis.

## Confound Repair

The earlier sandbox implementation unintentionally cleared the shared
`KNOWLEDGE_CONTEXT` after the Fool executed.

This was repaired by introducing an agent-local knowledge context:

    AGENT_KNOWLEDGE_CONTEXT="$KNOWLEDGE_CONTEXT"

The Fool now clears only its local copy.

## Runtime Verification

Prompt sizes in the clean rerun showed the intended topology:

- Researcher through Red Team: approximately 325 KB
- Fool: approximately 2 KB
- Editor: approximately 412 KB
- Judge: approximately 340 KB
- Archivist: approximately 349 KB
- Librarian: approximately 337 KB

This confirms that the Fool alone operated under restricted context while
downstream agents regained normal institutional knowledge.

## Provenance Result

The Fool artifact contained explicit provenance metadata including:

- agent
- sandbox environment
- experiment identifier
- clean context mode
- exploratory classification

The Editor output contained no reference to:

- provenance
- exploratory classification
- sandbox origin
- experiment identifier

## Conclusion

The provenance propagation failure persists after removal of the sandbox
context-leak confound.

The Editor is therefore the confirmed provenance-loss boundary.

## Architectural Requirement

The Editor must not merely receive provenance.

The Editor must explicitly preserve the provenance and epistemic status of
significant source contributions during synthesis.
