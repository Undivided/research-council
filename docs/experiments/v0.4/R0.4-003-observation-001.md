# R0.4-003 Observation 001

## Experiment

Cognitive Provenance Layer

## Finding

Provenance metadata was successfully attached to sandboxed Fool output at generation time.

The Fool artifact correctly recorded:

- generating agent
- sandbox environment
- experiment identifier
- context mode
- exploratory classification

However, the provenance did not survive downstream synthesis.

## Observed Chain

Fool artifact:

- provenance present
- exploratory classification present

Editor output:

- provenance absent
- sandbox classification absent

Judge output:

- provenance absent
- sandbox classification absent

Archivist output:

- provenance absent
- sandbox classification absent

## Failure Boundary

The provenance chain breaks at the Editor.

The Editor receives the source artifact but synthesizes its content without preserving the source's cognitive origin or classification.

## Interpretation

Provenance cannot be treated as passive metadata.

Any cognitive function that transforms information must preserve the provenance of significant contributing inputs.

## Architectural Requirement

Transformation stages require provenance propagation.

At minimum, synthesis should preserve:

- source agent
- source environment
- source classification
- experiment identifier
- whether the contribution was exploratory or evaluated

## Status

Provenance creation: PASS

Provenance propagation through synthesis: FAIL

Next step:
Update the Editor cognitive contract to preserve provenance through synthesis.
