# R0.4-001 Sandboxed Cognition

## Question

Can cognitive agents explore independently while preventing unvalidated ideas from becoming institutional memory?

## Context

Research Council v0.3 established:

- specialized cognitive functions
- multi-agent synthesis
- Judge-based reasoning evaluation
- Archivist-based institutional memory

The next limitation identified:

Agents currently operate in a shared workspace.

This creates a risk that:
- speculative ideas become prematurely trusted
- exploratory reasoning contaminates durable knowledge
- useful contradictions are discarded too early

## Hypothesis

Cognitive agents require isolated exploration environments.

A sandbox should allow:
- high-variance reasoning
- speculative exploration
- adversarial testing
- discarded attempts

without directly affecting institutional memory.

## Design Principles

Separate:

- exploration from acceptance
- ideas from knowledge
- disagreement from failure
- evaluation from approval

## Expected Benefits

- Fool can generate unusual hypotheses safely.
- Red Team can attack assumptions without damaging consensus.
- Researchers can explore without premature publication.
- Archivist receives reviewed knowledge rather than raw cognition.

## Open Questions

- How much sandbox history should survive?
- Should each cognitive function have different sandbox rules?
- Who controls promotion from sandbox to institutional memory?
- Can rejected ideas remain searchable without becoming trusted knowledge?

## Status

Initial design experiment for v0.4 sandboxed cognition.
