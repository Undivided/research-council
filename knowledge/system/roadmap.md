# System Roadmap

Future development direction for the Research Council.

---

## Current State

Completed:

- Multi-agent research council
- Specialized reasoning roles
- Persistent project reports
- Archivist knowledge extraction
- Librarian role
- System memory layer

Current limitation:

Knowledge exists but retrieval is primitive.

---

# Phase 1: Memory Foundation

Status:

In progress.

Goals:

- Preserve all research outputs
- Record system decisions
- Record failures
- Track improvements

Completed:

- Knowledge directory
- System memory directory
- Agent documentation

---

# Phase 2: Intelligent Retrieval

Status:

Planned.

Goals:

Allow agents to access relevant previous knowledge automatically.

Possible upgrades:

- Improved keyword search
- Metadata tagging
- Semantic embeddings
- Vector database
- Knowledge graph

Design principle:

Markdown files remain the human-readable source of truth.

---

# Phase 3: Self Evaluation

Status:

Planned.

Goals:

The council evaluates its own performance.

Capabilities:

- Compare agent outputs
- Score usefulness
- Identify weak reasoning patterns
- Recommend prompt changes

Potential new agent:

Systems Engineer

---

# Phase 4: Human-AI Knowledge Interface

Status:

Planned.

Goals:

Combine AI retrieval with human understanding.

Potential tools:

- Obsidian knowledge graph
- Visual concept mapping
- Timeline views
- Research navigation

Principle:

Humans explore.
AI retrieves.
Together they reason.

---

# Phase 5: Advanced Council Architecture

Status:

Future.

Possible capabilities:

- Multiple model comparison
- Specialized models per agent
- Automated literature ingestion
- Citation verification
- Experiment tracking
- Autonomous improvement proposals

---

# Guiding Principle

The council should improve not only its answers.

It should improve the process that creates answers.
