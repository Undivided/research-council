# Agent Performance

Track agent effectiveness and behavior.

---

## Purpose

The council contains specialized reasoning roles.

This file records observations about:

- usefulness
- weaknesses
- failure modes
- prompt improvements
- model suitability

---

## 2026-09-07

### Researcher Agent

Role:

Collect evidence and separate facts from claims.

Observed behavior:

Produces broad information gathering and establishes baseline knowledge.

Strengths:

- Good at identifying major factors
- Useful for first-pass analysis
- Creates foundation for other agents

Weaknesses:

- May accept existing assumptions too easily
- Requires skeptical review

Future improvement:

Add stronger source evaluation requirements.

---

## 2026-09-07

### Historian Agent

Role:

Identify historical patterns and precedents.

Observed behavior:

Useful for comparing current problems with previous examples.

Strengths:

- Provides context
- Identifies recurring patterns

Weaknesses:

- Historical analogy can become misleading
- Requires careful relevance checking

Future improvement:

Require explicit comparison criteria.

---

## 2026-09-07

### Philosopher Agent

Role:

Analyze definitions, assumptions, and logic.

Observed behavior:

Useful for identifying hidden premises.

Strengths:

- Finds conceptual errors
- Clarifies ambiguous questions

Weaknesses:

- Can become abstract without constraints

Future improvement:

Require connection between philosophy and actionable decisions.

---

## 2026-09-07

### Skeptic / Red Team Agents

Role:

Challenge conclusions.

Observed behavior:

Essential for preventing premature confidence.

Strengths:

- Finds weak assumptions
- Identifies missing evidence

Weaknesses:

- Excessive skepticism can slow decisions

Future improvement:

Require ranked criticisms by importance.

---

## 2026-09-07

### Archivist Agent

Role:

Convert research outputs into durable knowledge.

Observed behavior:

Created the first persistent knowledge entries.

Strengths:

- Preserves institutional memory
- Separates knowledge from temporary reports

Weaknesses:

- Requires access to previous knowledge

Future improvement:

Integrate with retrieval system.
