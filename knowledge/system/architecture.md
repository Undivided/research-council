# Research Council Architecture

## Core Principle

The council consists of three layers:

1. Storage layer
2. Retrieval layer
3. Reasoning layer


## Storage Layer

Purpose:

Preserve knowledge permanently.

Implementation:

Markdown files.

Characteristics:

- Human readable
- Portable
- Version controllable
- Model independent


## Retrieval Layer

Purpose:

Select relevant knowledge before reasoning.

Current implementation:

Keyword-based retrieval.

Future:

- Metadata
- Embeddings
- Vector search
- Knowledge graph


## Reasoning Layer

Purpose:

Analyze information.

Components:

- Researcher
- Historian
- Philosopher
- Strategist
- Skeptic
- Red Team
- Archivist
- Librarian


## Design Rule

Never couple knowledge storage directly to a specific AI model.

The knowledge belongs to the council, not the model.
