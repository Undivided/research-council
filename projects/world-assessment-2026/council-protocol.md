# Research Council Protocol

## Phase 1: Question Definition

Before research begins:

- Define the question.
- Define important terms.
- Identify assumptions.
- Identify what evidence would change the conclusion.

## Phase 2: Evidence Collection

Researcher collects:

- Primary sources where possible.
- Multiple perspectives.
- Source quality ratings.
- Dates and context.

## Phase 3: Historical Analysis

Historian examines:

- Previous examples.
- Long-term patterns.
- Similarities.
- Differences.

## Phase 4: Conceptual Analysis

Philosopher examines:

- Definitions.
- Assumptions.
- Logical consistency.
- Alternative frameworks.

## Phase 5: Strategic Analysis

Strategist examines:

- Actors.
- Incentives.
- Capabilities.
- Constraints.
- Information environments.

## Phase 6: Adversarial Review

Skeptic and Red Team attempt to:

- Find errors.
- Identify missing evidence.
- Challenge conclusions.
- Present strongest opposing arguments.

## Phase 7: Final Report

Editor produces:

- Known facts.
- Interpretations.
- Disagreements.
- Confidence levels.
- Unknowns.
- Final assessment.
