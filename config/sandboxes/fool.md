# Fool Sandbox Contract

## Purpose

Provide protected space for frame-breaking exploration.

## Allowed Inputs

- research question
- defined constraints
- relevant observations

## Restricted Inputs

Do not automatically provide:

- accepted conclusions
- previous synthesis
- institutional memory
- final judgments

## Cognitive Goal

Maximize:

- alternative frames
- assumption challenges
- unusual hypotheses
- contradiction discovery

## Output Classification

Fool output is:

EXPLORATORY

It is not:

- factual consensus
- institutional knowledge
- final recommendation

## Promotion Path

Fool ideas require:

Fool
  ↓
Editor
  ↓
Judge
  ↓
Archivist

before entering institutional memory.
